14A. PERCEPTUAL SPECIMEN UNIQUENESS — NO OBVIOUS DUPLICATE GEODES

A core V4 requirement is that two opened geodes should almost never look like obvious duplicates.

This does NOT require mathematically unique arbitrary geometry for every specimen.

It DOES require strong perceptual uniqueness.

Every specimen's deterministic seed and generated stats must visibly influence the result.

For two specimens of the SAME mineral family, visible differences should be able to come from combinations of:

overall size;

mass;

outer silhouette;

shell thickness;

cavity size;

cavity depth;

cavity shape;

number of chambers;

crystal size;

crystal density;

crystal spacing;

crystal orientation;

crystal habit proportions;

crystal transparency/clarity;

saturation;

hue;

color zoning;

brightness/value;

inclusions;

secondary mineral growth;

matrix thickness;

banding;

weathering;

exposed exterior clues;

rare centerpiece traits;

symmetry/asymmetry;

processing damage;

cut orientation;

polishing state.

A player should be able to place two Amethyst specimens beside each other and visibly understand why one is ordinary and the other is exceptional WITHOUT reading the value number.

Stats that supposedly differ but produce no perceivable difference should be redesigned, visually amplified within believable bounds, or removed from value weighting.

Same-material comparison test

Create deterministic side-by-side comparison tooling.

For each important mineral family, stage at least:

low-quality example;

average example;

high-quality example;

exceptional/rare example;

damaged example.

Place them under identical lighting and camera distance.

Ask:

can I immediately rank them visually?

can I see changes in color?

can I see crystal-scale differences?

can I see density differences?

can I see cavity differences?

can I see condition differences?

does the rare one actually look rare?

If not, improve the generator/materials.

Duplicate detection

Extend contact-sheet QA with similarity checks.

Look for:

repeated silhouettes;

repeated cavity layouts;

repeated crystal arrangements;

identical palette bands;

obvious seed-to-seed clones.

If two neighboring specimens look like the same model with tiny noise changes, the system fails this gate.

17B. CLEANING / PREPARATION — PHYSICAL BUT FAST

Add a concise cleaning/preparation step for rough material where appropriate.

This should support immersion and knowledge, not become repetitive janitorial work.

Possible sequence:

choose cracking/saw preparation.

Cleaning should be:

tactile;

visually satisfying;

short;

skippable or simplified for already-clean premium material where appropriate.

Target only a few seconds for normal rough.

Do not make every rock require a 30-second cleaning minigame.

Why cleaning matters

Cleaning can reveal:

natural seams;

stains;

tiny mineral exposure;

shell texture;

fractures;

void clues;

saw-worthy flat areas.

The player should occasionally change processing plans after cleaning.

Preparation for hammer/chisel

Before cracking, meaningful preparation may include:

selecting a support orientation;

rotating the rock to expose a promising seam;

selecting chisel profile;

clearing loose debris;

confirming the work area.

Keep prep fast once the player is experienced.

17D. TOOL SUITABILITY BY SPECIMEN SIZE / STRUCTURE

Not every specimen should be equally practical with hammer/chisel.

Create meaningful processing constraints.

Small / medium rough

Usually practical with hammer/chisel or saw.

Large rough

Hammer/chisel may be possible but:

requires more preparation;

takes longer;

needs stronger support;

may require working around more sectors;

has greater fatigue/time cost;

risks more damage if brute-forced.

Saw may be preferable depending on geology.

Oversized rough

May require:

upgraded heavy cradle;

larger saw;

splitting wedge / heavier chisel;

stronger hammer;

dedicated support fixture;

another appropriate mid/late-game processing station.

Do not simply disable the hammer with an arbitrary UI lock unless physically justified.

Where plausible, allow the player to attempt an oversized rock with basic tools, but make the drawbacks obvious:

very slow;

difficult;

unstable;

high risk;

inefficient.

The player should understand:

“I technically can try this, but I really need better equipment.”

This creates aspiration.

17E. HAMMER + CHISEL MUST NEVER BE PERFECTLY RELIABLE

The V3 hammer system is good; V4 should deepen skill without making it frustrating.

A correct-looking strike should not always produce identical progress.

Variation may depend on:

seam quality;

shell thickness;

strike angle;

force;

chisel profile;

support stability;

existing cracks;

Possible outcomes:

clean crack propagation;

weak progress;

slip;

local fracture;

interior damage;

no useful crack;

unexpectedly good propagation.

The player must be able to improve the odds with skill.

Do NOT make outcomes feel random and uncontrollable.

The rule is:

Skill shifts probability strongly, but geology still matters.

Value consequences

Poor processing can visibly reduce value through:

chipped crystal tips;

shattered field;

lost centerpiece;

shell damage;

ugly asymmetrical break;

A great geological specimen can become merely good if processed badly.

An ordinary specimen should not become world-class through perfect technique.

If a non-core polish issue has consumed roughly 20–30 minutes without clear convergence:
