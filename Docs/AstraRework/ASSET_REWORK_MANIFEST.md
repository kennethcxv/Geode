# Asset rework manifest — active inventory

This is a production inventory and action queue, not an acceptance list. It includes every FBX currently in the project, including assets whose live use still needs tracing, and the procedural/authored world families below. A file's existence or the old generator's “hero” description does not certify it. Assets that prove unused should be recorded as unused before removing or exempting them. Selected targets are in [ART_DIRECTION.md](ART_DIRECTION.md); limits are in [PERFORMANCE_BUDGET.md](PERFORMANCE_BUDGET.md).

Use the existing `Tools/Blender/gen_props.py`, `hq.py`, `gen_crystals.py`, `geode_blender_lib.py` and `render_props.py` pipeline. Save editable Blender sources for materially reauthored families, preserve Unity GUIDs where the asset replaces a current one, and record the exact source/export/render used. No production mesh has yet passed the Astra visual gate.
